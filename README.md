# AI Job Market Analysis (Power BI)

This project is a Power BI dashboard where I explored and analyzed trends in the AI job market.

## 📊 What this dashboard shows

* Job demand across different countries
* Top in-demand job roles
* Experience level distribution
* Average salary insights
* Work type analysis (Remote, Hybrid, Onsite)

## 🚀 Features

* Interactive dashboard
* Drill-through for country-level analysis
* Dynamic title using DAX
* Clean and simple design

## 🛠 Tools Used

* Power BI
* DAX

## 📌 About

This project helped me improve my skills in data visualization, dashboard design, and understanding real-world data.
